漏洩チェックの方法自分のパスワードやメールアドレスは漏れている？無料で確認する3つの方法

漏れていたときの対処法まで ・ 2026年11月10日 ・ ネットの鍵守 守屋

本記事はアフィリエイト広告（PR）を含みます。「PR」表示のあるリンクから商品を申し込むと、運営者に報酬が支払われることがあります。

アララ、無印良品、ノジマ、サントリー――漏洩のニュースが続き、「自分の情報も漏れているかもしれない」と感じている人は多いはずです。でも、企業からのお知らせを待っているだけでは、本当のところは分かりません。

実は、パスワードとメールアドレスは、無料で自分で確かめる方法があります。この記事では、確認する3つの方法と、漏れていたとき・漏れていなかったときにやることをまとめます。

さっそく確認してみる

今使っているパスワードが過去の流出データに含まれていないか、30秒で調べられます。パスワードそのものは送信されません。

流出チェッカーで確認する

自分で確認できること、できないこと

  • パスワード過去の流出データに、同じパスワードが含まれているか（何回登場したか）が分かる
  • メールアドレス世界の主な漏洩事件のデータに、そのメールアドレスが含まれているかが分かる
  • 特定の会社からの漏洩その会社の公式なお知らせで確認する。自分で調べる仕組みはない

どの方法も「データに載っていない＝絶対に漏れていない」という証明にはなりません。特に、発表されたばかりの国内の漏洩は、すぐにはデータに反映されないことがあります。

方法1：パスワードが漏れていないか調べる

当サイトの流出チェッカーでは、パスワードが過去の流出データに何回登場したかを調べられます。

  1. トップページの入力欄に、調べたいパスワードを入力します。
  2. 「確認する」を押します。
  3. 流出データに含まれていれば、その回数が表示されます。

入力したパスワードは、ブラウザの中で「ハッシュ値」という別の文字列に変換され、その先頭5文字だけが照合用のデータベース（Have I Been Pwned の Pwned Passwords）に送られます。パスワードそのものはどこにも送られず、当サイトにも保存されません。仕組みのプログラムは GitHub で公開しています。

スマホやブラウザに保存しているパスワードは、まとめて点検することもできます。Googleパスワードマネージャーの「パスワード チェックアップ」や、iPhone・Macの「パスワード」アプリの「セキュリティに関する勧告」では、流出が見つかったパスワードを知らせてくれます。

パスワードを1つずつ確認するなら

流出チェッカーなら、保存していないパスワードも確認できます。

無料でチェックする

方法2：メールアドレスが漏れていないか調べる

メールアドレスは、セキュリティ研究者の Troy Hunt 氏が運営するHave I Been Pwnedで調べられます。2013年から続く世界的に知られたサービスで、ブラウザのFirefoxやパスワード管理アプリの1Passwordにも、このサービスの漏洩チェックが組み込まれています。

  1. Have I Been Pwned を開きます（英語のサイトです）。
  2. トップの入力欄にメールアドレスを入れて、検索ボタンを押します。
  3. 含まれていれば、どの漏洩事件に入っていたか（サービス名や時期、漏れた項目）が一覧で表示されます。

海外の大きな漏洩事件が中心のため、国内の企業の漏洩は載っていないこともあります。「載っていない＝安全」ではない点に注意してください。

方法3：企業からのお知らせを確認する

特定の会社から漏れたかどうかは、その会社の公式サイトのお知らせで確認するしかありません。たとえばメール配信サービス「アララ」の件では、個人向けの照会窓口はなく、メールを受け取っていた各社がそれぞれ対象の期間や条件を発表しています（アララ流出の影響企業まとめ）。

このとき、届いたメールやSMSのリンクからではなく、自分で開いた公式サイトで確認してください。漏洩のお知らせを装った偽メールが出回ることがあるためです。

漏れていたときにやること

  1. パスワードが漏れていた今すぐ

    そのパスワードを使っているサービスを、すべて新しいパスワードに変えます。末尾に数字を足すような似たパターンではなく、まったく新しいものにしてください（理由は「パスワードを変えても意味ない」は本当？で解説しています）。メール、銀行・証券、通販、SNSから優先して変えます。

  2. メールアドレスが漏れていた今日から

    メールアドレスだけでログインされることはありません。ただ、そのアドレスに偽のお知らせやカード会社を装うメールが届きやすくなります。メールのリンクからは入力しないことを徹底し、そのアドレスで登録しているサービスのパスワードを使い回していないか確認します。

  3. どちらの場合も10分

    主要なサービスで二段階認証（またはパスキー）をオンにします。パスワードとメールアドレスがセットで漏れても、それだけではログインされなくなります。

漏れていなかったときは

ひとまず安心です。ただ、流出データに載っていないパスワードでも、短いものや、単語に数字を足しただけのものは、攻撃者に当てられやすいことに変わりはありません。サービスごとに別のパスワードにして、二段階認証をオンにしておくのが一番の備えです。

よくある質問

  • パスワードを入力して大丈夫？：流出チェッカーでは、パスワードそのものは送信も保存もされません。送られるのは、パスワードを変換した文字列の先頭5文字だけです。それでも気になる人は、確認したあとにそのパスワードを変えると安心です。
  • 何回漏れていたら危ない？：1回でも載っていれば、攻撃者が試すリストに入っていると考えてください。回数が少なくても、すぐに変えるのがおすすめです。
  • 定期的に確認したほうがいい？：大きな漏洩のニュースを見たときに確認する、くらいで十分です。むしろ、サービスごとにパスワードを分けて、二段階認証をオンにしておくことのほうが大切です。
