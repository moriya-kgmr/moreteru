漏洩はなぜ止まらない？サントリーも約10万人分。情報流出が相次ぐ4つの理由

利用者の守り方まで ・ 2026年11月3日 ・ ネットの鍵守 守屋

本記事はアフィリエイト広告（PR）を含みます。「PR」表示のあるリンクから商品を申し込むと、運営者に報酬が支払われることがあります。

2026年11月2日、サントリーホールディングスが、グループの従業員などおよそ10万人分の個人情報が漏洩したと発表しました。10月だけでも、通販サイト、航空会社、タクシー会社、新聞社などで漏洩の発表が続いています。

「なぜ、こんなにも続くのか」。この記事では、セキュリティ機関の注意喚起や公表データをもとに、漏洩が相次ぐ4つの理由を整理します。そのうえで、利用者にとって何が変わったのか、どう身を守ればいいのかをまとめます。

まずは今のパスワードを確認

どの会社から漏れても、最初に狙われるのはパスワードの使い回しです。流出データに載っていないか、無料で調べられます。

注目したいのは、漏れたのが「お客さん」ではなく、従業員や就職活動の応募者の情報だったことです。10月30日に発表された日本交通の件でも、約29万人分のうち最も多いのは採用の応募者（約10万8,000人）でした。商品を買っていなくても、応募や登録をしただけの会社から情報が漏れる。それが今の漏洩の特徴の一つです。

無料でチェックする

情報流出が相次ぐ4つの理由

  1. 古い「穴」がふさがれないまま残っている

    JPCERT/CC（国内のセキュリティ対応の調整機関）は10月9日、国内で相次ぐ不正アクセスについて注意喚起を出しました。そこで最初に挙げられているのが、すでに知られている脆弱性（ソフトの弱点）を探して突く攻撃です。修正版が出ていても、更新されていないシステムや、設定の不備が残ったままの機器が狙われています。

    10月には、Webサイトで広く使われているプログラミング言語PHPで深刻な脆弱性が見つかり、修正版の公開前に情報が漏れ出す騒ぎもありました。国内でも多くのサービスが緊急メンテナンスに追われました。

  2. 画面の「裏口」が狙われている

    同じ注意喚起では、アプリやシステムどうしをつなぐ「API」を悪用した不正操作も挙げられています。公開されているスマホアプリを解析して、画面からは操作できない内部の仕組みに直接アクセスし、権限を書き換えたり、不正なアカウントを作ったりする手口です。

    社内向けのデータ分析ツールや管理システム、外部のクラウドサービスなど、利用者からは見えない場所が入口になるケースが増えています。サントリーの件も、グループが使う外部のクラウドサービスへの不正アクセスでした。

  3. 盗まれた「鍵」が使い回されている

    攻撃者は、ある場所で盗んだIDやパスワード、システムの認証キーを、別の場所で使います。JPCERT/CCは、他のシステムへの侵害で盗まれたAPIキーが使われた例も報告しています。10月に発表された日本経済新聞社の約183万件の漏洩も、クラウドにアクセスするための認証情報が盗まれたことが原因とされています。

    これは、個人がパスワードを使い回して乗っ取られる仕組みとまったく同じです。1か所で漏れた鍵が、次の侵入の入口になる。漏洩が連鎖しやすいのはこのためです。

  4. 攻撃の手間が下がり、数が増えている

    警察庁によると、脆弱性を探すような不審なアクセスは、1日・1IPあたり13,687件と、前年同期（9,085.4件）の約1.5倍に増えました。送信元の大部分は海外です。国の資料では、AIを悪用して攻撃の大部分を自動で実行した例も報告されています。

    ただし、個々の漏洩でAIが使われたと確認された情報は、今のところ多くありません。「AIのせいで急増した」と言い切れる段階ではないことにも注意が必要です。

一方で、セキュリティ会社ラックのCTOは、攻撃そのものが短期間に急増したというより、各社の調査と公表の時期が重なった面も大きいと指摘しています。不正アクセスの発覚から公表までには、調査のために数週間〜数か月かかることがあります。日本交通の件も、不正アクセスは7月で、詳しい公表は10月でした。

流出チェッカーを使う

利用者にとって、何が変わったのか

  • 「使っていない会社」からも漏れる：採用の応募、イベントの登録、昔の会員登録。どこに情報を渡したか覚えていない会社からも、漏洩の連絡が来る時代です。
  • 漏れてから知るまでに時間がかかる：調査には時間がかかるので、通知が届いたときには、漏洩から何か月もたっていることがあります。
  • 漏れた情報は「次の攻撃」の材料になる：名前やメールアドレスは偽のメールやSMSに、パスワードは別のサービスへのログインの試行に使われます。

つまり、「どこから漏れたか」を追いかけるより、どこから漏れても被害につながらない状態を先に作っておくほうが現実的です。

今日からやること

  1. パスワードの流出を確認する：流出チェッカーで、今使っているパスワードを調べます。
  2. 使い回しをやめ、二段階認証をオンにする：1か所で漏れた鍵で、他の扉まで開けられないようにします。変え方のコツは「パスワードを変えても意味ない」は本当？で解説しています。
  3. 会社を名乗る連絡のリンクは開かない：「お詫び」「確認のお願い」の連絡は、公式サイトやアプリから確かめます。
  4. 使っていない登録を整理する：退会できるサービスは退会して、漏れる場所そのものを減らします。
