「自分のパスワードは大丈夫」と思っていませんか。

世界中で流出したパスワードを集めたデータベース「Pwned Passwords」に、日本人が使いがちなパスワード25個を照合し、それぞれ何回登場するかを調べました（2026年10月30日計測）。

結果、1位の「123456」は約2億1,046万回。日本らしい「sakura」でも約68万回、「pokemon」は約214万回でした。自分や家族が使っていないか、ランキングで確認してみてください。

流出チェッカーで確認する

結果からわかったこと

  • 数字の並びは桁違い：「123456」は約2億1,046万回、2位の「12345678」も約7,061万回です。上位5件のうち3件が「数字を順に押すだけ」のパスワードでした。
  • 好きなキャラの名前も筒抜け：「pokemon」約214万回、「naruto」約164万回と、日本発の作品名は100万回を超えています。世界中にファンがいるので、攻撃者が使う単語リストにも当然入っています。
  • 「日本語なら安全」は思い込み：「sakura」は約68万回、野球の「tigers」は約57万回、名字の「suzuki」も約39万回でした。
  • キーボードの並びもバレている：縦になぞる「1qaz2wsx」は一見ランダムですが、約583万回も登場しています。
  • 回数が少なくても安全ではない：最下位の「osaka」でも4,780回漏れています。一度でも登場したパスワードは攻撃用のリストに載り、「先に試される候補」になります。「19900101」のような生年月日も、組み合わせが少ないので総当たりで簡単に試せます。

「覚えやすい」ものは「当てやすい」。漏洩回数は、そのまま攻撃者が試す順番だと考えてください。

ランキングにないパスワードも漏れているかも

思いつきで作ったつもりのパスワードでも、すでに誰かと同じ可能性があります。

無料でチェックする

調べ方と安全性

調査には、セキュリティ研究者の Troy Hunt 氏が運営する「Have I Been Pwned」の Pwned Passwords API を使いました（調査日：2026年10月30日）。

このAPIには、パスワードそのものを送りません。パスワードを「ハッシュ値」という別の文字列に変換し、その先頭5文字だけを送ります。返ってきた候補との照合は手元で行うため、どのパスワードを調べたかは相手のサーバーにも分かりません。当サイトのチェックツールも同じ仕組みで動いていて、ソースコードは GitHub で公開しています。

流出チェッカーを使う

今日からやること

  1. 自分のパスワードを確認する：ランキングにないパスワードでも、漏洩している可能性があります。流出チェッカーで確認してみてください。
  2. 使い回しをやめる：1つ漏れると、同じパスワードを使っている全サービスが危険になります。
  3. パスワード管理機能を使う：サービスごとに違う強いパスワードを自動で作り、覚えておいてくれます。パスワード管理機能付きのセキュリティソフトは下のランキングで紹介しています。
  4. 二段階認証を設定する：パスワードが漏れても、それだけではログインされなくなります。
